# Course Map

MCP Security Engineering follows the same notebook-first progression as the
Awesome AI Agents example. Every topic owns its chapter, reusable lab, and one
canonical notebook.

## Beginner track

- 01 — MCP architecture, lifecycle, and trust boundaries
- 02 — Threat modeling MCP and agent protocols
- 03 — Secure tool, resource, and prompt interfaces
- 04 — Building a minimal secure MCP server
- 05 — Client/host security and capability negotiation

## Intermediate track

- 06 — MCP authentication and OAuth security
- 07 — Authorization and policy enforcement
- 08 — Delegation, token exchange, and confused deputy
- 09 — Runtime isolation and sandboxing
- 10 — Filesystem, network, SSRF, and egress security
- 11 — Prompt injection, tool poisoning, and untrusted content
- 12 — Supply-chain provenance, SBOMs, signing, and dependencies
- 13 — Secure MCP CI/CD and release gates

## Advanced track

- 14 — MCP security testing and fuzzing
- 15 — MCP red teaming and adversarial evaluation
- 16 — Runtime observability and continuous assurance
- 17 — Server registry, discovery, trust, and enterprise gateways
- 18 — Agent-to-Agent security and delegation
- 19 — Protocol composition security
- 20 — Multi-agent and cross-server attack paths
- 21 — Incident detection, containment, and forensics
- 22 — Recovery, revocation, rollback, and resilience
- 23 — Enterprise MCP security architecture
- 24 — MCP identity and non-human identity governance
- 25 — MCP security governance and risk management
- 26 — MCP supply-chain risk management
- 27 — MCP security observability and SOC integration
- 28 — MCP threat hunting and runtime anomaly detection
- 29 — MCP security architecture review workshop
- 30 — Integrated secure MCP platform capstone

Course 30 integrates the recurring tenant-support scenario across signed
release, runtime authorization, idempotent effects, observability, containment,
recovery, and reauthorization. Ongoing improvements are tracked in the
[roadmap](ROADMAP.md).
