# Shared and migrated course material

The numbered track directories are the canonical learner path. This directory
keeps reusable or historically migrated material outside that progression:

- `reference/` contains the original cross-cutting guides and worksheets that
  informed the colocated lessons.
- `legacy-labs/` preserves earlier compact labs and notebooks for provenance
  while the canonical lessons use their own `lab.py` and notebook.

New learner-facing work belongs in a numbered topic unless it is genuinely
shared by multiple lessons.
